# Uzay İneği Araştırma Enstitüsü (Statik Site)

Bu proje, tamamen kurgusal ve hiciv amaçlı hazırlanmış çok sayfalı bir **saf HTML + CSS + JS** sitesidir.

## Nasıl açılır?
- Proje klasöründe `index.html` dosyasını çift tıklayıp doğrudan tarayıcıda açabilirsiniz.
- Tüm yollar göreli tanımlandığı için `file://` modunda ve herhangi bir statik hosting ortamında çalışır.

## Dosya yapısı
- `index.html` — Ana sayfa, hero, öne çıkan kanıtlar, tanık kartları, bilim bölümü
- `kanitlar.html` — Kanıt arşivi, filtrelenebilir dosya kartları, detay modalı
- `roportajlar.html` — 6 tanık röportajı, transkript modalı, tanıklık puanı hesaplayıcı
- `bilimsel.html` — Sahte-akademik açıklamalar, karşılaştırmalı tablo, zaman çizelgesi, İnekçe Çevirmeni
- `galeri.html` — Arşiv galerisi, tanık portreleri, lightbox ve filtreler
- `hakkimizda.html` — Enstitü tarihçesi, ekip, etik ilkeler, SSS, iletişim formu
- `css/style.css` — Tüm sayfaların ortak stilleri
- `js/script.js` — Tüm sayfalarda çalışan ortak vanilya JS etkileşimleri
